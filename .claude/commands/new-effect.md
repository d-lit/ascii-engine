Новый эффект: $ARGUMENTS

1. Сверься с SPEC §6–7: тип эффекта, сигнатура, схема параметров.
2. Предложи схему параметров (имена, диапазоны, дефолты) и кратко алгоритм. Дождись подтверждения.
3. Реши, кто делает:
   - cell/displace по существующему интерфейсу с понятным алгоритмом — оформи задачу для Codex через шаги `/plan-task` (образец — ближайший эффект того же типа);
   - system, или нужен новый контракт, или алгоритм неочевиден — делай сам.
4. Если делаешь сам: файл `src/effects/<kind>/<id>.ts`, регистрация в `registry`, без аллокаций на ячейку и кадр, случайность только через `ctx.rand`, тест на маленьком поле для cell/displace, пример в пресете. `npm run check`, отчёт.
