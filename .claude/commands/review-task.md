Проведи ревью задачи $ARGUMENTS из `docs/tasks/`.

1. Прочитай постановку, отчёт исполнителя и `git diff` по затронутым файлам.
2. Проверь:
   - изменены только разрешённые файлы;
   - инварианты из `AGENTS.md` соблюдены (особенно аллокации в горячем цикле и работа с яркостью, а не символами);
   - публичные интерфейсы не изменены без согласования;
   - тесты действительно проверяют критерии приёмки, а не просто существуют;
   - `npm run check` проходит.
3. Проверь `docs/OPEN-QUESTIONS.md` на вопросы и временные решения по этой задаче; ответь на них, при необходимости обнови SPEC и DECISIONS.
4. Запиши итог в раздел «Ревью»: принято или список замечаний.
5. Принято — статус `done`, отметь пункт в ROADMAP, предложи сообщение коммита. Есть замечания — статус `ready` с замечаниями в постановке, чтобы Codex доработал.
