# Выполнение задачи из docs/tasks/

Вход: номер задачи (например, `012`) или «следующая». Для «следующей» возьми задачу `ready` с наименьшим номером.

1. Прочитай `AGENTS.md`, файл задачи и все разделы `docs/SPEC.md` и файлы-образцы, на которые она ссылается.
2. Проверь статус. Не `ready` — остановись и сообщи.
3. Поставь `Статус: in-progress (Codex)`.
4. Сверь постановку с кодом. Если чего-то не хватает (тип не существует, образец не найден, критерий непроверяем) — запиши вопрос в `docs/OPEN-QUESTIONS.md` со ссылкой на задачу, поставь `blocked`, остановись.
5. Реализуй, меняя только файлы из раздела «Файлы». Соблюдай инварианты из `AGENTS.md`.
6. Напиши или обнови тесты из раздела «Критерии приёмки».
7. Запусти `npm run check`. Не проходит — чини, пока не пройдёт, или опиши блокер.
8. Заполни «Отчёт исполнителя»: что сделано, отклонения, что проверить в браузере, предложенный коммит.
9. Поставь `Статус: review`. Не коммить.
