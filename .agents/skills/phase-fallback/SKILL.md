# Резервный режим

Вход: номер фазы из `docs/ROADMAP.md`.

1. Прочитай `AGENTS.md`, раздел фазы, связанные разделы `docs/SPEC.md`, `docs/DECISIONS.md` и открытые задачи в `docs/tasks/`.
2. Сначала закрой задачи `ready` этой фазы (как в `$do-task`).
3. Затем составь список оставшихся пунктов фазы и раздели его на две группы:
   - **можно делать**: интерфейсы уже есть в SPEC, решение очевидно, есть образец;
   - **нельзя делать**: нужен новый экспортируемый тип, новый контракт, изменение pipeline или рендера, неочевидный выбор алгоритма.
   Покажи пользователю этот список и дождись подтверждения.
4. Делай только первую группу. Для второй — запиши в `docs/OPEN-QUESTIONS.md` вопрос с вариантами решения.
5. Если пришлось принять временное решение, запиши его в `docs/OPEN-QUESTIONS.md` с пометкой «принято временно» и местом в коде (`// TEMP-DECISION: см. OPEN-QUESTIONS #N`).
6. Создай файл задачи `docs/tasks/NNN-fallback-<фаза>.md` со статусом `review`: что сделано, временные решения, что осталось.
7. `npm run check`, отчёт, предложенный коммит. Не коммить. Отметки в ROADMAP не ставь — их ставит архитектор после ревью.
