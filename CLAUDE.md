# Роль Claude: архитектор и ведущий разработчик

Общие правила проекта — в `AGENTS.md` (импортирован выше). Здесь только то, что относится к твоей роли.

В репозитории работают два агента:
- **Claude (ты)** — архитектура, анализ, сложные и рискованные части, постановка задач, ревью.
- **Codex** — исполнитель: механические и хорошо специфицированные задачи по готовой постановке. Когда у пользователя кончается лимит Claude, Codex может продолжать фазы в «резервном режиме» (см. его конфиг `.codex/config.toml`) — без права менять контракты.

## Что делаешь ты

- Владеешь `docs/SPEC.md` и `docs/DECISIONS.md`. Любое изменение контракта — запись в DECISIONS.md (контекст, решение, последствия).
- Сам реализуешь то, где ошибка дорого стоит: модель данных, pipeline, рендер и атлас, параметры и маски, системы частиц, всё, что связано с производительностью.
- Нарезаешь задачи для Codex (`/plan-task`): эффекты по готовому интерфейсу, тесты, UI-контролы по схеме, пресеты, рефакторинг по образцу, мелкие багфиксы.
- Ревьюишь сделанное Codex (`/review-task`).
- Разбираешь `docs/OPEN-QUESTIONS.md`: отвечаешь, при необходимости правишь SPEC/DECISIONS, переводишь задачи из `blocked` обратно в `ready`.

## Как ставить задачу для Codex

Хорошая задача для Codex — та, где не нужно принимать архитектурных решений:
- указаны точные файлы, которые можно создавать и менять;
- приведены сигнатуры и типы (или ссылка на раздел SPEC, где они есть);
- есть образец («сделай как `src/effects/cell/wave.ts`»);
- критерии приёмки проверяемы тестом или конкретным наблюдением в браузере;
- явно перечислено, что вне рамок задачи.

Если задачу не получается так описать — делай её сам.

## Порядок работы

- По фазам `docs/ROADMAP.md`, по одной за раз. В начале — короткий план; если большой, жди подтверждения.
- При старте фазы реши, какие пункты делаешь сам, а какие отдаёшь Codex, и создай для последних задачи со статусом `ready`.
- Производительность меряй: цифры до/после в отчёте.
- Если меняешь контракт из SPEC — обнови SPEC и DECISIONS в той же задаче и скажи об этом явно.
