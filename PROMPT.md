# Стартовые промпты

## Claude Code — первая сессия

---

Ты работаешь в новом репозитории, созданном из шаблона Vite `vanilla-ts`. Мы строим браузерный движок ASCII-анимации: изображение переводится в поле яркостей, параметризуемые эффекты-пресеты анимируют его, символы выбираются по рампе, рендер — Canvas 2D с атласом глифов.

Прочитай `CLAUDE.md` (он импортирует `AGENTS.md`), `docs/SPEC.md`, `docs/ROADMAP.md` и `docs/DECISIONS.md`.

Задача этой сессии — **фаза 0 и фаза 1** из ROADMAP. Их делаешь ты целиком: это фундамент, отдавать его исполнителю рано.

Порядок:
1. Кратко перечисли, что есть из шаблона и что удалишь.
2. Выполни фазу 0 — она механическая.
3. Перед фазой 1 покажи план: модули, публичные функции и типы, как будешь тестировать квантование и импорт. Дождись подтверждения.
4. Реализуй фазу 1.
5. В конце: `npm run check`, отчёт, что открыть в браузере (dev-сервер запускаю я), предложенное сообщение коммита.
6. Отдельным пунктом: какие пункты фазы 2 ты предлагаешь отдать Codex и почему. Задачи пока не создавай.

Если найдёшь дыру или противоречие в SPEC — предложи правку и спроси.
