## Контекст

Модуляция параметров (LFO, огибающие) через расширяемый реестр источников — следующим источником станет MIDI (фаза 4.5). Маски и `mix` (SPEC §6.4), пресеты (SPEC §8), панель цепочки. Цветовой контракт фиксируется заранее (DECISIONS 015), реализация цвета — позже. Каждый чанк заканчивается зелёным `npm run check` и отметкой здесь; продолжать с первого неотмеченного.

## Чанки

- [x] **1. Модуляция и цветовой контракт.** Источники значения: константа, LFO (`sine/triangle/saw/square/noise`), огибающая (`linear/smooth`, `loop`), отсчёт от активации эффекта; реестр источников для будущих (MIDI). DECISIONS 015 (цвет), ROADMAP 4.5 (WebMIDI). Тесты.

## Отчёт исполнителя

**Чанк 1.** `pipeline/modulation.ts`: реестр `ModSource` (ключ-маркер + `resolve(value, t)`), встроенные `lfo` (формы `sine/triangle/saw/square/noise`, все стартуют с минимума, `phase` — доля периода) и `env` (удержание концов, `loop`, `smooth`), с проверкой формы значения. `params.ts`: именованные `LfoValue`/`EnvValue`/`ModValue`, `resolveNumber` и `resolveParams` получают часы модуляции `t`. `ChainEntry.activatedAt` ставится при добавлении, включении, `restart` и смене источника. DECISIONS 015 (цвет), ROADMAP фаза 4.5 (WebMIDI), SPEC §2, §7. Тестов: 164 → 177.

**Чанк 2.** `pipeline/mask.ts`: `fillMask` раз в кадр в буфер эффекта (`alpha`, `lum` — по исходнику; `radial` — изотропно, радиус модулируется; `rect` — нормированный прямоугольник, мягкий край внутрь; `invert`). `Pipeline`: у `ChainEntry` поля `mix` (ParamValue, часы модуляции эффекта) и `mask`; `add(def, values, { mix, mask })`, `setMask`, `move`; стадии смешивают по весу `mix·mask` (cell — все числовые поля и `r,g,b`, `char` по порогу 0.5; displace — масштаб смещения), при весе 0 эффект не вызывается. Буферы масок пересоздаются при смене размера источника. SPEC §6.4.

Замер (CPU pipeline 200×100, медиана): без масок все четыре cell 4.25 → 4.54 мс, все десять 7.21 → 7.56 мс (+5–7% на проверку веса); все десять с `mix` по LFO и радиальной маской у курсора — 2.55 мс (вне маски эффекты не вызываются). Сборок нет. Тестов: 177 → 188.

**Чанк 3.** `presets/preset.ts`: типы `Preset`/`PresetEffect`, `validatePreset` (никогда не бросает; предупреждения по каждому битому полю, неизвестные параметры игнорируются молча), `parsePreset` (JSON-ошибка — тоже предупреждение), `chainToPreset`, `serializePreset` (поля по умолчанию опускаются), `applyChain` (замена цепочки с копированием значений). Блок `color` зарезервирован. Встроенные пресеты: `Liquid portrait`, `Dissolve loop` (огибающая с повтором на пороге erosion), `Pointer lens` (dark-on-light, маска у курсора), `Broadcast glitch` (`mix` по square-LFO). `tsconfig`: `resolveJsonModule`. SPEC §8. Тестов: 188 → 200 (встроенные без предупреждений, 500 случайных мусорных входов без исключений, сохранение → загрузка даёт те же 20 кадров).

**Чанк 4.** `ui/controls.ts` переписан: общие `row/selectOf/checkbox/button/slider`; `numberControl` — переключатель `const / lfo / env` (LFO: форма, частота, min, max, фаза; огибающая: точки текстом `t:v, …`, `loop`, `ease`), модулированные значения правятся на месте; `maskControl` — тип маски, `invert` и поля по типу (радиус радиальной маски тоже модулируется). `ui/panel.ts` — `ChainPanel`: встроенные пресеты, имя, загрузка и сохранение JSON (предупреждения в консоль и строку статуса), добавление любого эффекта (повторно тоже), карточки с вкл/выкл, ↑ ↓ ✕, сворачиванием, `mix`, маской и параметрами. `main.ts`: pipeline создаётся при старте на пустом поле 1×1 (цепочку и пресет можно настроить до загрузки картинки), панель разделена на секции `view / preset / chain / export`, при старте применяется первый встроенный пресет. Панель шире: 320 px. Тестов: 200 → 203.

**Чанк 5.** Встроенные пресеты на 200×100 (CPU pipeline, медиана / p95): Liquid portrait 2.81 / 2.90 мс, Dissolve loop 2.85 / 3.28, Pointer lens 0.96 / 1.05, Broadcast glitch 3.12 / 4.16; сборок нет (0–1 за 600 кадров). Импорты JSON с атрибутом `with { type: 'json' }` — модуль пресетов грузится и в Vite, и в чистом Node.

### Что проверить в браузере

1. Старт: панель `preset` показывает Liquid portrait; после загрузки фото — сразу течение, рябь у курсора и проявление `decode`.
2. Переключить все четыре встроенных пресета: меняются рампа/полярность и цепочка; Pointer lens — светлая тема.
3. `chain`: добавить `ripple` дважды (разные настройки), переставить ↑ ↓, выключить, удалить; свернуть/развернуть карточку.
4. Числовой параметр → `lfo`: значение «дышит»; `env` с `loop` — повторяется; некорректная строка точек подсвечивается красным и не ломает анимацию.
5. `mix` < 1 — эффект ослаблен; `mix` в режиме `lfo` — эффект появляется и исчезает.
6. Маски: `radial` у курсора с мягким краем, `rect`, `lum` (эффект только на светлом), `invert`.
7. `save` → `load…` того же файла: та же картина. Битый JSON или чужой файл — сообщение в строке статуса, предупреждения в консоли, без падения.
8. Консоль без ошибок; оверлей при пресетах — fps 60.
