## Отчёт исполнителя

**Чанк 1.** `core/color.ts` (`Rgb`, `parseHex`, `toHex`, `isHexColor`; `parseHex` переехал из рендера). `pipeline/colorize.ts`: `ColorMode`, `GradientStop`, `ColorSettings`, `buildGradientLut` (256 значений, сортировка точек, удержание концов), `colorize`. `EffectDef.writesColor` → такие cell-эффекты выполняются в стадии `post` после раскраски (DECISIONS 016). `Pipeline.setColor(settings, ink)`; канал цвета создаётся и убирается по требованию в `rebuild`; тайминг `post` в оверлее. Импорт фото всегда с цветом. Тестов: 209 → 217.

**Чанк 2.** `Compositor`: при `work.color !== null` — цветной путь `composeColor`. Для изменившейся ячейки строится палитра на 33 уровня (фон → чернила ячейки, фиксированная точка, по сложению на канал), пиксель берёт `pal[(coverage·alpha) >> 11]` — как в монохроме, одна выборка. Ключ изменения ячейки: символ, шаг `alpha` и цвет с допуском 3 бита на канал (рисуется точный цвет, отставание < 8/255). Переход между монохромом и цветом перерисовывает всё. Упаковка пикселя не зависит от порядка байт платформы.

Композиция 200×110 при градиенте (каждая ячейка меняет цвет каждый кадр — худший случай), медиана мс, ячейка 6×11 / 12×22:

| вариант | grad wave | grad all four |
|---|---|---|
| попиксельное смешивание | 3.59 / 12.83 | 2.96 / 10.64 |
| палитра на ячейку, `Math.round` | 4.79 / 9.76 | 5.70 / 9.24 |
| палитра, фиксированная точка | 2.92 / 7.55 | 2.51 / 6.22 |
| + допуск ключа цвета | **1.87 / 4.83** | **2.00 / 4.45** |

Монохром не изменился (wave 0.55, all four 0.92 мс при 6×11). Статичный цветной кадр 0.38 мс. Основная оставшаяся цена — запись пикселей перерисованных ячеек, а не палитры (эксперимент: без построения палитр 2.12 мс против 2.86). Сборок нет (1–3 за 400 кадров — фон прогрева). Тестов: 217 → 221.

**Чанк 3.** Пресет: `color: { mode, stops }` (`ColorSettings`), валидация точек (1–8 штук, `pos` 0..1, hex), при ошибке — градиент по умолчанию с предупреждением; `stops` сохраняются только в режиме `gradient`; предупреждение «не рисуется» убрано.
