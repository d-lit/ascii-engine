## Отчёт исполнителя

**Чанк 1.** `README.md` (EN): что это, ссылка на демо, возможности (списки эффектов, рамп, режимов, форматов экспорта сверены с кодом: 13 эффектов, 10 встроенных пресетов, 5 рамп, размеры офлайн-рендера), быстрый старт через yarn, ссылки на документы, стек, лицензия; место под главный ролик помечено комментарием до чанка 6. `docs/README.md` — карта документов (для пользователя / для разработчиков, кто ведёт, где что искать). `docs/guide/README.md` — оглавление руководства с пометками «скоро», чтобы ссылка из README не вела в пустоту. `LICENSE` (MIT), `"license": "MIT"` в `package.json`.

**Чанк 2.** `guide/01-start.md` — путь до первого ролика, пять главных настроек, как читать курсор / `restart` / оверлей / статус, ширина панели. `guide/02-panel.md` — все секции в порядке панели (`view`, `color`, `background`, `preset`, `chain`, `export`, `video`): каждая настройка, значение по умолчанию, отметка «хранится в пресете»; отдельно — карточка эффекта, переключатель `const / lfo / env`, контрол точки. Подписи, диапазоны и значения по умолчанию сверены с `main.ts`, `ui/panel.ts`, `ui/controls.ts`. Ссылки на ещё не написанные разделы 03–07 оживут в следующих чанках.

**Чанк 3.** `guide/03-layers-and-colour.md`: схема трёх слоёв (фон кадра → плашки → символы), прозрачность ячеек как окно в нижние слои, таблицы по каждому слою (цвета темы — из `THEMES` в `main.ts`), порядок вычисления кадра и почему градиент реагирует на эффекты яркости, таблица «что попадает в экспорт», 11 рецептов, частые недоразумения.
