## Отчёт исполнителя

**Чанк 1.** `README.md` (EN): что это, ссылка на демо, возможности (списки эффектов, рамп, режимов, форматов экспорта сверены с кодом: 13 эффектов, 10 встроенных пресетов, 5 рамп, размеры офлайн-рендера), быстрый старт через yarn, ссылки на документы, стек, лицензия; место под главный ролик помечено комментарием до чанка 6. `docs/README.md` — карта документов (для пользователя / для разработчиков, кто ведёт, где что искать). `docs/guide/README.md` — оглавление руководства с пометками «скоро», чтобы ссылка из README не вела в пустоту. `LICENSE` (MIT), `"license": "MIT"` в `package.json`.

**Чанк 2.** `guide/01-start.md` — путь до первого ролика, пять главных настроек, как читать курсор / `restart` / оверлей / статус, ширина панели. `guide/02-panel.md` — все секции в порядке панели (`view`, `color`, `background`, `preset`, `chain`, `export`, `video`): каждая настройка, значение по умолчанию, отметка «хранится в пресете»; отдельно — карточка эффекта, переключатель `const / lfo / env`, контрол точки. Подписи, диапазоны и значения по умолчанию сверены с `main.ts`, `ui/panel.ts`, `ui/controls.ts`. Ссылки на ещё не написанные разделы 03–07 оживут в следующих чанках.

**Чанк 3.** `guide/03-layers-and-colour.md`: схема трёх слоёв (фон кадра → плашки → символы), прозрачность ячеек как окно в нижние слои, таблицы по каждому слою (цвета темы — из `THEMES` в `main.ts`), порядок вычисления кадра и почему градиент реагирует на эффекты яркости, таблица «что попадает в экспорт», 11 рецептов, частые недоразумения.

**Чанк 4.** `guide/04-effects.md`: все 13 эффектов по группам, по каждому параметру — подпись из панели, полный диапазон, значение по умолчанию, интересный диапазон (= подсказка `random`), заметка; выгружено из схем эффектов. `guide/05-motion-and-masks.md`: часы эффекта, `const / lfo / env` (поля, значения при переключении — из `ui/controls.ts`), рецепты модуляции, `mix` (порог 0.5 для символа), маски (поля, значения при выборе, что `alpha`/`lum` смотрят на исходник), центр эффекта (поведение курсора до первого движения и после ухода), порядок цепочки по группам. В `PRESETS.md` таблицы эффектов заменены ссылками на руководство; приёмы, сочетания, цвет, фон и стоимость остались там.

**Чанк 5.** `guide/06-presets.md`: что хранится в пресете и что нет, таблица 10 встроенных пресетов (состав выгружен из JSON), сохранение и загрузка, `random`, как пополнить встроенные. `guide/07-export.md`: выбор способа, текст, PNG, запись против рендера, рабочий цикл для соцсетей (`replay take` + `from start`), настройки, прозрачное видео (OpenReel, мобильный CapCut), обходы для редакторов без альфы (Screen / Multiply / Chroma key), ограничения браузеров. `guide/08-faq.md`: строки оверлея, что ускоряет (с расчётом роста работы от `cols`), частые вопросы. Оглавление руководства и карта документов без пометок «скоро».

**Чанк 6** отложен пользователем; место под ролик в README помечено комментарием, пункт перенесён в ROADMAP (фаза 6).

**Чанк 7.** `AGENTS.md`: раздел «Документация пользователя» (изменение настройки, эффекта, параметра, режима или формата экспорта обновляет руководство в той же задаче, числа — из кода) и новый пункт 2 в правилах завершения задачи; руководство добавлено в источники правды.
