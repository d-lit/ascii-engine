## Отчёт исполнителя

**Удалено:** `ripple` режим `beat`; у `particles` — `beat force`, `center (beat)`; у `sand` — `beat radius`, `center (beat)`; у огибающей — `on: 'beat'`; `FrameContext.beat` и его расчёт в pipeline; `findOnsets`, `lastOnset`, `beatBetween` (`audio/bands.ts`); `forEachHeard` (`audio/track.ts`) и их тесты.

**Явные силы:**
- `particles`: второй толкатель `center push` (0–3000, ускорение (1 − d/r) из `center`) + `center` + `center radius`; клик получил свой `click radius` (бывший `blast radius`). Толкатели — общий код с курсором. Под толкателем частица не засыпает, только пока сила больше `spring · 0.02`: иначе слабый остаток силы (длинный хвост баса в дБ) держал бы все частицы круга в воздухе.
- `sand`: `center crumble` (0–20 доли/с) + `center` + `center radius` — своё осыпание в круге.

**Шаг по звуку** (`audio/steps.ts`, `pipeline/modulation.ts`, `pipeline/points.ts`):
- пересечения порога по сырой полосе с гистерезисом 0.08, кеш на таблице по (полоса, порог с точностью 0.01); номер шага — двоичный поиск по позиции трека, время с последнего шага — для `glide`; без состояния кадра;
- числа: `{ step, threshold, mode: random | cycle | add, min, max, values?, by?, glide?, seed? }` — новый источник модуляции `step` в реестре; валидация пресетов — автоматически;
- точки: `{ step, threshold, mode: random | grid | list, area?, points?, glide?, seed? }`; отличается от числового отсутствием `min`; точечные источники читают `ModEnv` через `currentModEnv()`;
- отклонение от плана: у точки вместо `path` — `list` (свой список позиций): проще и понятнее, а траектории на шагах — лишняя сложность. SPEC §7.3 описывает реализованное.

**Панель:** режим `step` у числа (`band`, `threshold`, `mode`, `min`, `max`, `values` / `by` / `seed`, `glide, s`), режим `audio step` у точки (`band`, `threshold`, `jump to`, область / список, `glide, s`). Индикаторы четырёх полос в секции `audio` (`ui/band-meters.ts`): сырые уровни в момент транспорта, отметки на ¼, ½, ¾; обновляются, только пока видны.

**Пресеты:** **Beat drop** — рябь, пульс и вспышка: сила на `audio bass`, центр — `audio step` `grid` (прыгают вместе по сетке 3×3). **Beat burst** — `center push` на `audio bass`, центр — `audio step` `random`, вспышка там же, `trails` (`sprites`) — взрыв на каждой бочке в новом месте, с хвостами.

**Документация:** руководство (карта панели — режимы `step` и `audio step`, индикаторы; «Движение и маски» — раздел `step`, «удар — это просто громкий бас», рецепты; эффекты — `ripple`, `particles`, `sand`; пресеты), `PRESETS.md`, README, SPEC §7.2, §7.3, §13.

**Тесты:** 401 → 406 (пересечения и номер шага; шаг для чисел: режимы, удержание, glide, без трека, валидация; для точек: grid, random в области, валидация; толчок из центра по басу; осыпание в круге). Удалены тесты ударов.

5. Перемотка и офлайн-рендер Beat burst — прыжки на тех же ударах.
6. Старый сохранённый пресет с `beat` (если есть) — грузится с предупреждением.

**Правка после проверки пользователем.** Замечания: `pulse` почти незаметен, хотя индикаторы прыгают резко; `liquid` + `ripple` + `pulse` — «желе» без границ эффектов; пресеты должны быть фундаментом для старта, а не «отключить половину, чтобы понять, что происходит».
- Причины вялости (в механизмах): хвост бочки в дБ держит полосу на 0.4–0.6, параметр ходит от середины до `max`; `pulse` — свой маятник, звук менял только его силу.
- `audio` получил `floor` (0–0.9 в панели): ниже — тишина, остальное растягивается на 0..1.
- `pulse`: `frequency` от 0; при 0 — постоянный сдвиг на `amount` (с `amount` на `audio` — «насос»).
- Правило пресетов «одна роль — один эффект» (`PRESETS.md`, таблица ролей). Пересобраны: Liquid portrait (`liquid` + `decode`), Pointer lens (`lens` + `pulse`), Broadcast glitch (`glitch-rows` + `pulse`), Neon tide (`liquid` + `wave`), Prism (`swirl` + `hue-cycle`), Thermal spotlight (`erosion` + `tint`), Orbit lens (`lens` + `glow` на одной орбите), Beat drop (`ripple` на басу по сетке + `pulse`-насос контраста на верхах), Shatter (только `particles`), Beat burst (`particles` + `trails`), Comets (`particles` + `trails`). Остальные уже укладывались в правило.
