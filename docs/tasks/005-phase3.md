## Контекст

## Отчёт исполнителя

**Чанк 1.** `core/sample.ts`: `sampleChannel`/`sampleLum`/`sampleAlpha`/`sampleColor` (билинейно, clamp, центры ячеек — целые координаты), `distIso`. `Pipeline.runDisplace`: цепочка displace-функций двигает переиспользуемый `Vec2`, веса билинейной выборки считаются один раз на ячейку для всех каналов, авторский `char` — ближайший, `charOverride` обнуляется; без displace-эффектов — прежняя копия. Стадия `copy` в таймингах и оверлее переименована в `sample`. Тестов: 137 → 147.

**Чанк 2.** `effects/displace/ripple.ts`: `continuous` — синус по изотропному радиусу от `center` с затуханием `exp(−d/decay)`; `click` — пул из 8 колец (Float64Array, без аллокаций), кольцо запускается кликом внутри canvas, волновой пакет ±2 длины волны вокруг фронта, гаснет за `life`. `swirl` — поворот в изотропном пространстве, угол `angle·(1−d/r)²`, `wobble` качает его синусом. `lens` — масштаб `1 − strength·(1−q)²`, плавно сходит на нет к радиусу, увеличение в центре `1/(1−strength)`. Все три берут текущую точку из `out` (композиция цепочки). Displace-эффекты стоят в панели первыми. Тестов: 147 → 155 (изотропность ripple по X и Y, кольца по клику, сохранение расстояния у swirl, lens в обе стороны).

**Чанк 3.** `liquid` — два независимых fbm3-поля (второе со сдвигом), смещение до `amplitude` по каждой оси в ширинах ячейки. `glitch-rows` — полосы по `band` строк; `rate` раз в секунду случайная доля `amount` полос сдвигается на целое число ячеек до `maxShift` (хеши только от целых). `shake` — одно смещение на кадр для всех ячеек, `smooth` (шум) или `jitter` (скачки с частотой `frequency`); смещение кадра хранится в `Float64Array`, а не в переменных замыкания: запись дробного числа в замыкание выделяет память. Тестов: 155 → 163.

## Ревью

Саморевью архитектора. Визуальная приёмка пройдена пользователем.


**Чанк 4.** Замер показал мусор (~1 МБ/кадр) в displace-стадии с `ripple`, `liquid`, `shake`. С `--no-maglev` чисто: `runDisplace` исполнялся кодом Maglev, который упаковывал результат тернарника `at.x < 0 ? 0 : …` (целая константа + double). Прижим переписан через `Math.min/max` — остаток 3–6 сборок не растёт с числом кадров (600 и 3000 дают одно и то же), то есть это прогрев JIT. Дополнены DECISIONS 013 и инвариант 4 в `AGENTS.md`.

`liquid` переведён на грубую решётку: поле течения считается раз в кадр с шагом 4 колонки (и ≈4 ширины ячейки по вертикали) и интерполируется билинейно в текущей точке `out` — композиция сохраняется. В шум добавлена форма без дробных аргументов `io` + `fbm3io`, на неё переведены `liquid` и `erosion`. SPEC §6.1 дополнен.

Сама displace-стадия (выборка без эффектов) ≈ 0.35 мс — это база для любого displace. Сборок за кадр нет. Композиция рендера с displace не дороже, чем с cell-эффектами (0.4–1 мс). Тестов: 137 → 164.

### Что проверить в браузере

1. `ripple` (continuous) — волны от курсора круглые, не эллипсы; символы меняются плавно, без «лесенки» (критерий фазы). Режим `click` — по клику расходится кольцо, несколько кликов дают несколько колец.
2. `swirl` — воронка в центре, `wobble` качает её туда-обратно.
3. `lens` под курсором — увеличение при `strength` > 0, «рыбий глаз» при < 0, край линзы без шва.
4. `liquid` — плавное течение без видимой сетки (если заметна решётка шага 4 — сказать).
5. `glitch-rows` — рывки полос строк, `shake` — дрожание (по краям растягиваются крайние ячейки — это clamp; сказать, если раздражает).
6. Комбинации: `lens` + `liquid`, `ripple` + `decode` — эффекты складываются.
7. 200 cols, несколько displace + cell-эффектов: цифры `sample`/`cell`/`render`/`total` и fps.
