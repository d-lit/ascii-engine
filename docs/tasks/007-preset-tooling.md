## Контекст

Подбор пресетов — отдельный, почти механический контур работы. Чтобы он шёл быстро: новый JSON в `src/presets/` появляется в списке без правки кода, есть справочник по эффектам и приёмам, есть генератор случайных цепочек для поиска. Каждый чанк заканчивается зелёным `npm run check` и отметкой здесь.

## Чанки

- [x] **1. Автоподхват пресетов.** `import.meta.glob` по `src/presets/*.json`, порядок по имени файла; тест «каждый встроенный пресет валиден без предупреждений» остаётся.
- [x] **2. Генератор случайных цепочек.** Чистая функция от сида: 2–4 эффекта, displace раньше cell, параметры в «интересных» диапазонах (необязательная подсказка `random` в схеме числового параметра), иногда LFO и маска. Результат всегда проходит валидацию без предупреждений. Кнопка в панели.
- [x] **3. Справочник.** `docs/PRESETS.md`: формат, эффекты и их интересные диапазоны, приёмы с LFO/огибающими/масками/mix, рабочий цикл подбора.

## Отчёт исполнителя

**Чанк 1.** `presets/builtin.ts` собирает все `src/presets/*.json` через `import.meta.glob` (eager), порядок — по имени файла; встроенные переименованы в `01-…04-…`. Тест порядка; тест валидности без предупреждений покрывает любой новый файл автоматически. Тестов: 203 → 204.

**Чанк 2.** `NumberSpec.random?: [min, max]` — необязательная подсказка диапазона для генератора (без неё — полоса ±15% размаха вокруг default); подсказки проставлены у ключевых параметров всех десяти эффектов. `presets/random.ts`: `randomChain(effects, seed, options)` — 2–4 разных эффекта, не больше двух displace, displace впереди; числа со снапом к шагу схемы; с вероятностью 0.35 один параметр эффекта получает LFO, 0.15 — `mix` по LFO, 0.2 — маска (радиальная у курсора или полоса яркости); цвет не трогается. Кнопка `random` в секции пресетов: применяет цепочку с текущими рампой и полярностью, сид пишется в имя (`Random 123456`) и строку статуса. Контракт схемы расширен (SPEC §7). Тестов: 204 → 209 (детерминизм, лимиты и порядок на 300 сидах, валидация без предупреждений, прогон в pipeline).

**Чанк 3.** `docs/PRESETS.md`: рабочий цикл (random → доводка → save → файл в `src/presets/` → `npm run check`), критерии хорошего пресета, формат записи, единицы, таблицы эффектов с интересными диапазонами (совпадают с подсказками `random`), приёмы с LFO, огибающими, масками и `mix`, рабочие сочетания и чего избегать, стоимость эффектов.

### Что проверить в браузере

1. Список встроенных пресетов тот же и в том же порядке.
2. `random` несколько раз подряд: каждый раз новая цепочка, в имени и строке статуса сид; рампа и полярность не меняются; ничего не падает.
3. Положить любой сохранённый JSON в `src/presets/` под именем `05-test.json`: он появляется в списке после перезагрузки страницы (dev-сервер подхватит сам).
