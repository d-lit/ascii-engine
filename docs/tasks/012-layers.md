## Отчёт исполнителя

**Шаг 0.** Временная кнопка `alpha test` (`export/alpha-probe.ts`) — 3 с 640×360 VP9 с альфой. Пользователь: файл кодируется, `ffprobe` — `alpha_mode=1`; OpenReel накладывает с прозрачностью и мягким краем; мобильный CapCut — чёрный фон, ступенчатый край. Решено ориентироваться на OpenReel. Пробник удаляется в шаге 2.

**Шаг 1.** `Compositor` пишет прозрачный слой символов: пиксель = чернила с альфой `покрытие × alpha ячейки`, пустое — 0; палитра на ячейку больше не нужна (альфа — одна операция на пиксель), `setColors(bg, fg)` → `setInk(fg)`. `render/backdrop.ts`: `Backdrop` (`theme` / `color` / `transparent`), `backdropFill`, `paintFrame` (фон, затем `drawImage` слоя). `Canvas2DRenderer`: слой символов в отдельном холсте, кадр пересобирается только при изменении слоя или фона; `setBackdrop`; основной холст с альфой; при прозрачном фоне — шахматка под холстом (CSS). Офлайн-рендер собирает кадр тем же `paintFrame`. Пресет: блок `backdrop` с валидацией (картинка не хранится), часть «вида» вместе с рампой, полярностью и цветом. Панель: секция `background` (режим, свой цвет — по умолчанию хромакейный зелёный); `save PNG` в секции `export`. SPEC §8, §9.1.

Композиция 200×110 (Node, медиана, мс, ячейка 6×11): монохром без изменений (static 0.33 → 0.36, all four 0.92 → 0.97); цвет быстрее — grad wave 1.87 → 1.54, grad all four 2.00 → 1.57. Сборок нет. `drawImage` двух слоёв меряется только в браузере (оверлей `render`).

### Что проверить в браузере

1. Без изменений настроек всё выглядит как раньше (тема, цвета, `blocks` без щелей). Оверлей `render` — сравнить с прежними ~1.5 мс.
2. `background` → `color`: фон своего цвета; `transparent`: шахматка под символами, сквозь `erosion` (`hide`) и маски видно шахматку.
3. `save PNG` с прозрачным фоном — в просмотрщике прозрачность на месте.
4. Пресет с фоном `color` сохраняется и загружается обратно.
5. Запись и офлайн-рендер с фоном `color` — цвет в ролике. С `transparent` в MP4 будет чёрный — это ожидаемо до шага 2.
