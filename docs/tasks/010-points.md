## Отчёт исполнителя

**Чанк 1.** `params.ts`: `POINT_MIN = -0.5`, `POINT_MAX = 1.5`, нормированная позиция прижимается к ним при разрешении. Валидация пресетов: позиция вне диапазона → default с предупреждением. `random`: точка — default (30%), курсор (20%), один из девяти якорей (35%) или свободная позиция в −0.25…1.25 (15%). `ui/controls.ts`: `pointControl` вместо выпадающего списка — сетка 3×3 (подсвечен текущий якорь, `center` = середина), кнопка `cursor`, у позиции ползунки `x`/`y` −0.5…1.5; тот же контрол у центра радиальной маски. Тестов: 252 → 255.

### Что проверить в браузере

1. У `ripple` / `swirl` / `lens` / `pulse` / `decode`: клик по любой из девяти точек сетки переносит центр, текущая подсвечена; `cursor` возвращает курсор.
2. Ползунки `x`/`y`: плавное перемещение; за край (например `x` = −0.3) — дуги вместо кругов у `ripple`/`swirl`.
3. Радиальная маска: тот же контрол.
4. `random` несколько раз — центры в разных местах. Сохранить → загрузить — позиция на месте.
