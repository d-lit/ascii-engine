# 6. Пресеты

Пресет — сохранённый «вид» вместе с цепочкой эффектов. Выбор пресета заменяет текущую цепочку целиком.

## Что хранится в пресете, а что нет

| в пресете | не в пресете (настройки сессии) |
|---|---|
| рампа, полярность | исходная картинка или текст, звуковая дорожка, `cols`, холст (`canvas`) и кадрирование исходника |
| цвет символов, градиент, плашки | `quantize`, `source chars`, `debug` |
| фон кадра: режим, свой цвет, настройки картинки (`fit`, `opacity`, `dim`, `blur`, `picture` / `custom`) | **сама картинка-подложка** и её кадрирование (`crop`, `zoom`) |
| цепочка: эффекты, их параметры (в том числе `lfo` / `env`), `mix`, маски, включены ли | настройки экспорта и видео |

Поэтому пресет с фоном `image` + `custom` после загрузки покажет вашу текущую картинку-подложку, а если её нет — цвет темы с подсказкой.

## Встроенные пресеты

Подбирались так, чтобы хорошо смотреться на любой картинке и жить без курсора. Каждый — 1–3 эффекта разных ролей (правило — в [PRESETS.md](../PRESETS.md)): это фундамент для своих экспериментов, каждый эффект в нём виден сам по себе. **Wandering light** и **Dissolve to photo** рассчитаны на фото: с текстовым исходником подложки не будет. Если пресет реагирует на мышь, это указано.

| пресет | что происходит | из чего собран |
|---|---|---|
| **Liquid portrait** (при старте) | картинка течёт, при включении символы проявляются из шума | `liquid` + `decode` |
| **Dissolve loop** | по кругу растворяется в шум и собирается обратно, поверх — лёгкие волны | `wave` + `erosion` с огибающей на `threshold`; рампа `long` |
| **Pointer lens** | светлая тема: линза у курсора «дышит», вокруг неё пульс | `lens` (сила по LFO) + `pulse` с маской у курсора |
| **Broadcast glitch** | сломанный телевизор: рывки полос включаются и выключаются, мигает контраст | `glitch-rows` (`mix` по square-LFO) + `pulse` (контраст); рампа `blocks` |
| **Neon tide** | неоновый градиент течёт, яркие полосы медленно вращаются | цвет `gradient` (неон) + `liquid` + `wave` с вращением направления |
| **Prism** | цвета фото с радужным переливом, мягкая воронка | цвет `source` + `swirl` + `hue-cycle` |
| **Thermal spotlight** | «тепловизор»: огненный градиент у курсора, вне его — синий тон и эрозия | цвет `gradient` (огонь) + `erosion` и `tint` (`multiply`) с инвертированной маской у курсора; рампа `blocks` |
| **Mosaic** | цветная мозаика из клеток фото, пульс и белая подсветка у курсора | цвет и плашки `source` + `pulse` + `glow` |
| **Ember glow** | тлеющие угли: огненный градиент на символах и плашках, течение, пульсирующее свечение у курсора | цвет и плашки `gradient` (огонь) + `liquid` + `glow` (радиус по LFO) |
| **Dissolve to photo** | ASCII по кругу растворяется в саму фотографию и собирается обратно | фон `image` (`picture`, `grid`) + `erosion` (`hide`) с огибающей; только для картинок |
| **Wandering light** | по ASCII блуждает «окно» в фотографию; наведите мышь — окно пойдёт за курсором | фон `image` (`picture`) + `erosion` (`hide`) с маской `radial`: курсор, когда его нет — `wander` |
| **Orbit lens** | линза кружит по океанскому градиенту, с другой стороны орбиты за ней гонится свечение | цвет `gradient` + `lens` и `glow` на одной орбите со сдвигом фазы 0.5 |
| **Beat drop** | под музыку: на каждой бочке рябь перескакивает по сетке 3×3 и бьёт, на хэтах качается контраст всей картинки. Без трека — спокойная картинка | цвет `gradient` + `ripple` (`amplitude` на `audio` `bass`, центр — `audio step` `grid`) + `pulse` (`global`, `contrast`, без колебаний, `amount` на `audio` `high`); загрузите трек в секции `audio` |
| **Shatter** | картинка собирается из разбросанных осколков в цветах фото; курсор расталкивает символы, клик взрывает | цвет `source` + `particles` (`intro` `scatter`, `cursor push`, клик) |
| **Beat burst** | символы падают сверху и собираются, потом на каждой бочке взрываются в новом месте, за ними хвосты | цвет `gradient` + `particles` (`intro` `rain`, `center push` на `audio` `bass`, центр — `audio step` `random`) + `trails`; загрузите трек в секции `audio` |
| **Comets** | символы слетаются с кольца вокруг картинки, курсор и клик разбрасывают их, за каждым тянется огненный хвост | цвет `gradient` (огонь) + `particles` (`implode`) + `trails` |
| **Crumble** | фото в своих цветах понемногу осыпается песком в горку у нижнего края и собирается обратно; клик обрушивает кусок | цвет `source` + `sand` + `trails` (`sprites`) |
| **Op art** | монохромные полосы бегут и медленно поворачиваются, переворачивая картинку под собой | `bands` (`invert`) |
| **Sonar** | из блуждающей точки расходятся кольца блочных символов поверх зелёного «радара»; кольца толстеют на басу | цвет `gradient` + `rings` (`ramp` `blocks`, `thickness` на `audio` `bass`) |
| **Screensaver** | пульсирующее пятно отскакивает от краёв, как заставка DVD | цвет `gradient` (неон) + `pulse` и `glow` на траектории `bounce`; рампа `blocks` |

## Сохранить и загрузить

- **`save`** скачивает текущие настройки как JSON. Имя берётся из поля `name`.
- **`load…`** загружает JSON. Файл, сделанный руками или в старой версии, не сломает приложение: всё, что не разобралось, заменяется значением по умолчанию, в строке статуса — сколько было предупреждений, подробности в консоли браузера (F12).
- Пресет можно открыть в любом текстовом редакторе: формат простой и описан в [PRESETS.md](../PRESETS.md).

## random — поиск идей

`random` собирает случайную цепочку из 2–4 эффектов:
- не больше двух `displace`, они идут первыми;
- параметры — из «интересных диапазонов» (см. [Эффекты](04-effects.md));
- иногда один параметр получает LFO, `mix` — LFO, эффект — маску;
- центры ставятся то на курсор, то в разные точки картинки, иногда — на медленную орбиту или блуждание.

Рампа, полярность, цвет и фон **не меняются**. Сначала выберите вид (например, градиент и подложку), потом жмите `random` и ищите движение.

Номер варианта попадает в имя (`Random 123456`). Понравилось — доведите руками и сохраните.

## Как пополнить встроенные пресеты

Положить JSON в `src/presets/` под именем `NN-kebab-name.json` (номер задаёт место в списке) — он появится в списке сам. Рабочий цикл, критерии хорошего пресета и проверка — в [PRESETS.md](../PRESETS.md).
