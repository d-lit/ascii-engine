# 4. Эффекты

16 эффектов в четырёх группах. Для каждого — что он делает, все параметры (как они подписаны в панели), полный диапазон, значение по умолчанию и **интересный диапазон** — где обычно живут хорошие результаты. Из этих же диапазонов берёт значения кнопка `random` (системой — не больше одной в цепочке).

Единицы:
- **cells** — ширины ячейки, одинаково по горизонтали и вертикали, поэтому круги остаются кругами;
- секунды — от включения эффекта;
- яркость — 0…1.

Любой числовой параметр можно перевести в `lfo` или `env` (см. [Движение и маски](05-motion-and-masks.md)).

## Displace: двигают картинку

Сдвигают, *откуда* берётся картинка: сами символы не меняют, меняют то, что под ними. Всегда выполняются раньше всех `cell`-эффектов. Несколько `displace` складываются по порядку цепочки.

### ripple — рябь

Круговые волны от точки. `continuous` — непрерывно из `center`; `click` — кольцо расходится от каждого клика (до 8 колец сразу). Под музыку — `audio` на `amplitude`: волна бьёт в такт басу.

| параметр | диапазон | по умолч. | интересно | заметки |
|---|---|---|---|---|
| `mode` | continuous / click | continuous | | |
| `center (continuous)` | точка | cursor | | только для `continuous` |
| `amplitude, cells` | 0–6 | 1.5 | 0.5–3 | сила смещения |
| `wavelength, cells` | 2–80 | 12 | 6–30 | расстояние между гребнями |
| `speed, cells/s` | 0–120 | 24 | 8–40 | 0 — застывшие кольца |
| `fade radius, cells` | 0–200 | 40 | 15–80 | на каком расстоянии волны затухают; 0 — не затухают |
| `ring life, s` | 0.5–10 | 3 | | только для `click`: сколько живёт кольцо |

### swirl — воронка

Закручивает картинку вокруг точки: сильнее в центре, к краю радиуса сходит на нет.

| параметр | диапазон | по умолч. | интересно | заметки |
|---|---|---|---|---|
| `center` | точка | центр | | |
| `angle, deg` | −720…720 | 180 | −360…360 | поворот в самом центре; знак — направление |
| `radius, cells` | 1–200 | 30 | 15–60 | |
| `wobble, Hz` | 0–3 | 0.25 | 0–0.5 | качание туда-обратно; 0 — неподвижная воронка |

### lens — линза

Увеличивает или уменьшает картинку в круге. Край линзы без шва.

| параметр | диапазон | по умолч. | интересно | заметки |
|---|---|---|---|---|
| `center` | точка | cursor | | |
| `radius, cells` | 2–100 | 18 | 10–35 | |
| `strength` | −1…0.9 | 0.5 | −0.6…0.7 | больше 0 — увеличение, меньше 0 — «рыбий глаз» |

### liquid — течение

Картинка течёт по плавному шумовому полю, как под водой.

| параметр | диапазон | по умолч. | интересно | заметки |
|---|---|---|---|---|
| `amplitude, cells` | 0–10 | 2 | 0.5–4 | насколько далеко утекают символы |
| `scale, cells` | 4–100 | 20 | 10–50 | размер вихрей |
| `speed` | 0–2 | 0.3 | 0.05–0.6 | скорость изменения течения |
| `octaves` | 1–4 | 2 | | мелкие детали течения; больше — дороже |

### glitch-rows — глитч

Горизонтальные полосы рывками сдвигаются вбок.

| параметр | диапазон | по умолч. | интересно | заметки |
|---|---|---|---|---|
| `rate, 1/s` | 0.5–30 | 6 | 2–12 | сколько раз в секунду меняется рисунок |
| `amount` | 0–1 | 0.15 | 0.05–0.3 | доля сдвинутых полос |
| `band, rows` | 1–20 | 3 | | высота полосы в строках |
| `max shift, cells` | 0–60 | 12 | 4–25 | наибольший сдвиг |

### shake — дрожание

Вся картинка дрожит как целое.

| параметр | диапазон | по умолч. | интересно | заметки |
|---|---|---|---|---|
| `mode` | smooth / jitter | smooth | | `smooth` — как камера в руке, `jitter` — резкие скачки |
| `amplitude, cells` | 0–5 | 0.6 | 0.1–1.2 | |
| `frequency, Hz` | 0.5–60 | 8 | 3–20 | |

## Cell: меняют ячейки

Работают с яркостью, прозрачностью и символом каждой ячейки после `displace`.

### wave — волна

Бегущие полосы яркости.

| параметр | диапазон | по умолч. | интересно | заметки |
|---|---|---|---|---|
| `direction, deg` | 0–360 | 0 | | 0 — вправо, 90 — вниз |
| `wavelength, cells` | 2–200 | 24 | 8–60 | ширина полосы |
| `speed, waves/s` | −5…5 | 0.5 | −1…1 | знак — направление движения |
| `amplitude` | 0–1 | 0.3 | 0.05–0.35 | 0.05–0.12 — лёгкое мерцание без потери картинки |

### pulse — пульсация

Яркость или контраст пульсируют: вся картинка разом или кольцами от точки. С `frequency` 0 маятника нет: эффект просто прибавляет `amount` — поставьте `amount` на `audio`, и картинка будет качаться в такт музыке (пресет **Beat drop**).

| параметр | диапазон | по умолч. | интересно | заметки |
|---|---|---|---|---|
| `shape` | global / radial | radial | | `radial` — кольца от `center` |
| `target` | brightness / contrast | brightness | | `contrast` при `amount` > 0.4 выжигает светлое |
| `center` | точка | cursor | | для `radial` |
| `frequency, Hz` | 0–5 | 1 | 0.2–2 | 0 — без колебаний, постоянный сдвиг на `amount` |
| `amount` | 0–1 | 0.35 | 0.1–0.45 | сила |
| `ring spacing, cells` | 2–200 | 30 | 10–60 | для `radial` |
| `fade radius, cells` | 0–200 | 25 | 10–60 | затухание колец; 0 — не затухают |

### erosion — эрозия

Шумовые «дыры», которые медленно текут. В `hide` дыры прозрачны: сквозь них виден фон (в том числе фото-подложка, см. [Слои и цвет](03-layers-and-colour.md)). В `darken` ячейки только темнеют.

| параметр | диапазон | по умолч. | интересно | заметки |
|---|---|---|---|---|
| `threshold` | 0–1 | 0.45 | 0.2–0.6 | 0 — всё на месте, 1 — всё стёрто; лучший параметр для огибающей |
| `softness` | 0–0.5 | 0.08 | 0.03–0.2 | мягкость края дыр |
| `scale, cells` | 2–100 | 14 | 6–40 | размер дыр |
| `speed` | 0–2 | 0.2 | 0.05–0.6 | скорость течения дыр |
| `octaves` | 1–5 | 2 | | рваность края; больше — дороже |
| `mode` | hide / darken | hide | | |

### decode — расшифровка

Картинка проявляется фронтом из точки: символы сначала мерцают случайными знаками, потом встают на свои места. Проигрывается заново при включении, по `|<` транспорта и на новой картинке.

| параметр | диапазон | по умолч. | интересно | заметки |
|---|---|---|---|---|
| `center` | точка | центр | | откуда идёт фронт |
| `front, cells/s` | 1–400 | 60 | 20–150 | скорость фронта |
| `scramble, s` | 0–3 | 0.6 | 0.2–1.5 | сколько мерцает каждая ячейка |
| `jitter, s` | 0–2 | 0.4 | 0–1 | разброс: фронт становится рваным |
| `flicker, 1/s` | 1–60 | 20 | | частота смены случайных знаков |
| `glyphs` | ascii / binary / hex / blocks | ascii | | чем мерцать |
| `hide before front` | вкл/выкл | вкл | | до фронта ячейки прозрачны (видно фон) |

## Красящие: цвет и плашки

Выполняются после раскраски по режиму цвета, поэтому всегда лежат сверху (подробно — в [Слоях и цвете](03-layers-and-colour.md)).

### tint — тонировка

Перекрашивает символы. Без маски действует на всю картинку, с маской `radial` у курсора — цветной «прожектор».

| параметр | диапазон | по умолч. | интересно | заметки |
|---|---|---|---|---|
| `color` | цвет | `#ff3b6b` | | |
| `blend` | replace / multiply / screen | replace | | `replace` — заменить цвет, `multiply` — затемнить через цвет (детали остаются), `screen` — осветлить к цвету |
| `amount` | 0–1 | 0.7 | 0.3–1 | |

### hue-cycle — перелив

Вращает оттенок символов во времени и вдоль картинки — радуга.

| параметр | диапазон | по умолч. | интересно | заметки |
|---|---|---|---|---|
| `speed, turns/s` | −2…2 | 0.1 | −0.3…0.3 | оборотов цветового круга в секунду |
| `spread, turns` | 0–4 | 1 | 0.2–2 | сколько оборотов укладывается на ширину картинки |
| `direction, deg` | 0–360 | 0 | | направление радуги |
| `saturation` | 0–1 | 0.6 | 0.3–1 | минимальная насыщенность: окрашивает даже серые символы (`mono`) |

### glow — свечение

Подсвечивает плашки ячеек вокруг точки. Работает и при `plates: none`.

| параметр | диапазон | по умолч. | интересно | заметки |
|---|---|---|---|---|
| `center` | точка | cursor | | |
| `color` | цвет | `#ffb347` | | |
| `radius, cells` | 1–120 | 16 | 6–40 | |
| `strength` | 0–1 | 0.8 | 0.4–1 | |
| `falloff` | 0.2–4 | 1.5 | 0.8–2.5 | форма спада: меньше — широкое пятно, больше — яркая точка в центре |

## System: символы с собственной жизнью

Системы помнят состояние между кадрами: символы срываются со своих мест, летят и возвращаются. Летящий символ продолжает показывать то, что сейчас в его ячейке (течение, `decode`, цвет), а ячейка на месте пустеет — вместе с плашкой. Осевший символ снова становится обычной ячейкой и ничего не стоит.

### particles — частицы

Каждый символ держится за своё место пружиной. Курсор и `center` расталкивают символы, клик взрывает их, пружина возвращает обратно; `intro` начинает с разбросанных символов, и картинка собирается сама (заново — по `|<`). Движение одинаково при любой частоте кадров и в офлайн-рендере. С маской двигается только то, что в маске; `mix` — сила всех толчков.

| параметр | диапазон | по умолч. | интересно | заметки |
|---|---|---|---|---|
| `intro` | none / scatter / rain / implode | none | | сборка на старте: `scatter` — из разбросанных по кадру, `rain` — падают сверху, снизу вверх ряд за рядом, `implode` — слетаются с кольца вокруг картинки |
| `spring` | 0.5–60 | 12 | 4–25 | сила пружины: больше — быстрее и резче возврат |
| `damping` | 0–20 | 3 | 1.5–6 | затухание: 0 — долго раскачивается, 8+ — возвращается без колебаний |
| `cursor push` | 0–800 | 0 | 100–400 | как сильно курсор расталкивает символы; 0 — не трогает |
| `push radius, cells` | 1–60 | 8 | 5–15 | размер «пустоты» вокруг курсора |
| `click force, cells/s` | 0–200 | 60 | 30–120 | взрыв по клику |
| `click radius, cells` | 1–200 | 30 | 15–60 | докуда достаёт взрыв по клику; к краю слабеет |
| `center push` | 0–3000 | 0 | 300–1500 | толчок из `center`: символы расступаются по кругу; 0 — выключен. Под музыку — `audio` `bass`: взрыв на каждой бочке |
| `center` | точка | центр | | откуда толчок; может двигаться по траектории или прыгать по звуку |
| `center radius, cells` | 1–200 | 30 | 15–60 | докуда достаёт толчок из `center` |
| `snap to cells` | вкл. / выкл. | выкл. | | символы прыгают по ячейкам, а не плывут — ретро-вид |

Пресеты: **Shatter** (сборка из осколков, курсор расталкивает, клик взрывает), **Beat burst** (под музыку: толчок из центра по басу), **Comets** (с хвостами `trails`).

### trails — шлейфы

Картинка помнит себя. Две части, можно по отдельности:
- **сетка** — каждая ячейка плавно тянется к своему прошлому значению: всё, что движется (течение, рябь, воронка, `wave`), оставляет затухающий след;
- **летящие символы** — слой частиц не стирается каждый кадр, а гаснет: за каждым символом тянется хвост.

Порядок с `particles` не важен. Без частиц работает только шлейф сетки. С маской шлейф сетки — только в маске; `mix` — сила (меньше — короче следы). На паузе шлейфы замирают вместе со всем.

| параметр | диапазон | по умолч. | интересно | заметки |
|---|---|---|---|---|
| `on` | both / grid / sprites | both | | что оставляет следы: всё, только сетка, только летящие символы |
| `fade, s` | 0.02–3 | 0.35 | 0.15–0.8 | за сколько след гаснет примерно втрое; не зависит от fps |

### sand — осыпание

Символы осыпаются с картинки песком: падают вниз, а если внизу занято — скатываются по диагонали, и копятся горкой у нижнего края **поверх** картинки. На месте осыпавшегося — дыра, сквозь неё виден фон. Через `return after` каждая песчинка плавно летит на своё место. Падают только на другие песчинки, поэтому крошится и сплошное фото. Движение по ячейкам, но плавное между шагами; одинаково при любой частоте кадров и в офлайн-рендере. С маской крошится только то, что в маске; `mix` — скорость крошения.

| параметр | диапазон | по умолч. | интересно | заметки |
|---|---|---|---|---|
| `crumble, share/s` | 0–0.3 | 0.02 | 0.01–0.06 | какая доля картинки отрывается за секунду; 0 — только по клику и вокруг `center` |
| `click radius, cells` | 0–60 | 8 | 5–15 | клик обрушивает круг такого радиуса; 0 — клик не действует |
| `center crumble, share/s` | 0–20 | 0 | 2–10 | своя скорость осыпания в круге вокруг `center`; 0 — выключено. Под музыку — `audio` `bass`: на каждой бочке обрушивается кусок |
| `center` | точка | центр | | центр круга; может двигаться |
| `center radius, cells` | 1–60 | 12 | 6–20 | размер круга |
| `fall, cells/s` | 5–60 | 25 | 15–40 | скорость падения |
| `return after, s` | 0.5–30 | 4 | 2–8 | сколько песчинка лежит до возврата |
| `flight home, s` | 0.1–3 | 0.7 | | сколько летит домой |

С `trails` (`sprites`, `fade` 0.15–0.25) за песчинками тянутся короткие хвосты — пресет **Crumble**.
