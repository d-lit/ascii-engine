# 3. Слои и цвет

Цвет в кадре задают три независимые вещи: фон под всем, плашки под символами и цвет самих символов. Если держать в голове эту схему, все настройки секций `color` и `background` встают на свои места.

## Три слоя

```
  ┌───────────────────────────────┐
  │  3. символы                   │  цвет: color → mode
  │     @ # % * + = - : .         │  + эффекты tint, hue-cycle
  ├───────────────────────────────┤
  │  2. плашки (фон каждой        │  color → plates, plate opacity
  │     ячейки, по умолчанию нет) │  + эффект glow
  ├───────────────────────────────┤
  │  1. фон кадра                 │  background → mode:
  │                               │  theme / color / transparent / image
  └───────────────────────────────┘
```

Слои лежат снизу вверх. Там, где верхнего слоя нет, виден нижний:
- между символами и вокруг них — плашка, если она включена;
- где нет ни символа, ни плашки — фон кадра.

## Прозрачность ячеек: окно в нижние слои

У каждой ячейки есть своя прозрачность. Её меняют эффекты:
- `erosion` в режиме `hide` — шумовые «дыры»;
- `decode` с `hide before front` — ячейки до прихода фронта;
- маски с `mix` — частично.

Прозрачная ячейка теряет и символ, и плашку: сквозь неё виден фон кадра. Отсюда главный приём последних версий:

> фон `image` + `picture` (исходное фото под символами) + `erosion` в `hide` → ASCII растворяется в саму фотографию и собирается обратно. Готовый пример — пресет **Dissolve to photo**.

## Слой 1: фон кадра (`background`)

| режим | что под символами | когда |
|---|---|---|
| `theme` | цвет темы: почти чёрный `#0b0b0d` при `light-on-dark`, бумажный `#f4f1ea` при `dark-on-light` | по умолчанию |
| `color` | любой цвет | фирменный цвет; зелёный — хромакей для монтажа |
| `transparent` | ничего (на экране шахматка) | PNG с прозрачностью, WebM-слой для видеоредактора |
| `image` | картинка (`picture` — исходное фото, `custom` — свой файл) с затемнением и размытием | ASCII поверх фото, растворение в фото |

`dim` и `blur` у картинки — для читаемости. Символы должны контрастировать с тем, что под ними: светлые символы (`light-on-dark`) читаются на затемнённом фото, тёмные (`dark-on-light`) — на светлом.

## Слой 2: плашки (`color → plates`)

Плашка — цветной прямоугольник под ячейкой, размером ровно с ячейку.

| режим | цвет плашки | эффект |
|---|---|---|
| `none` | — | по умолчанию |
| `source` | цвет фото в этой ячейке | мозаика: при `plate opacity` 1 картинка собирается из цветных клеток (пресет **Mosaic**) |
| `gradient` | градиент по яркости (тот же, что у символов) | цветная подложка, повторяющая светотень (пресет **Ember glow**) |
| `ink` | цвет символа этой ячейки | «подсветка» символов собственным цветом |

`plate opacity` 0.2–0.6 — символы читаются поверх плашек; 1 — плашки сплошные.

Эффект **`glow`** подсвечивает плашки вокруг точки (по умолчанию — курсора) своим цветом. Работает и при `plates: none`: тогда плашки есть только там, где светит `glow`.

## Слой 3: символы (`color → mode`)

| режим | цвет символа |
|---|---|
| `mono` | цвет темы: `#e8e6e3` на тёмном, `#16151a` на светлом |
| `source` | цвет фото в этой ячейке (у текстового исходника цветов нет — будет цвет темы) |
| `gradient` | градиент по яркости ячейки |

Поверх режима работают красящие эффекты:
- `tint` — перекрашивает в свой цвет: заменить (`replace`), затемнить через цвет (`multiply`), осветлить к цвету (`screen`);
- `hue-cycle` — радужный перелив по времени и по картинке. `saturation` раскрашивает даже серые символы, поэтому работает и в `mono`.

## Почему градиент «бежит» вместе с волной

Цвет считается **после** эффектов яркости. Порядок в каждом кадре:

1. `displace`-эффекты сдвигают картинку;
2. `cell`-эффекты меняют яркость, прозрачность, символы;
3. **раскраска** по `color → mode` (градиент смотрит на уже изменённую яркость);
4. **плашки** по `color → plates`;
5. **красящие эффекты** `tint`, `hue-cycle`, `glow` — поверх раскраски и плашек, в порядке цепочки;
6. всё это рисуется поверх фона кадра.

Отсюда:
- в режиме `gradient` эффекты `wave`, `pulse`, `erosion` (`darken`) дают цветные полосы, кольца и переливы без всякой настройки цвета;
- `tint` и `hue-cycle` нельзя «перебить» режимом цвета — они всегда сверху;
- менять порядок `tint` относительно `wave` в цепочке бесполезно: красящие эффекты всё равно идут после раскраски.

## Что попадает в экспорт

| | символы | цвет символов | плашки | фон кадра |
|---|---|---|---|---|
| текст (`copy`, `save .txt`) | да | — | — | — |
| `save PNG` | да | да | да | да (прозрачный — прозрачен) |
| запись и рендер, MP4 | да | да | да | да (прозрачный — станет чёрным) |
| запись и рендер, WebM | да | да | да | да, с прозрачностью |

## Рецепты: хочу → включаю

| хочу | настройки |
|---|---|
| ASCII поверх своей же фотографии | `background`: `image`, `picture`, `fit` `grid`, `dim` 0.5–0.7, немного `blur` |
| ASCII растворяется в фото и обратно | то же, `dim` ≈ 0.15 + `erosion` (`hide`) с огибающей на `threshold` — пресет **Dissolve to photo** |
| Фото видно только вокруг курсора | фон `image` + `picture`; эффект `erosion` в `hide` с `threshold` 1 и маской `radial` у курсора (символы исчезают в круге) |
| Цветная мозаика | `color → plates: source`, `plate opacity` 0.8–1; `mode: source` или `mono` |
| Неоновые переливы | `color → mode: gradient`, палитра `neon` + `wave` или `pulse` — пресет **Neon tide** |
| «Фонарик» у курсора | `glow` с центром `cursor`; для ярких символов — ещё `tint` с маской `radial` у курсора |
| Ретро-терминал | `mode: gradient`, палитра `phosphor` или `amber`, рампа `classic` или `binary` |
| Слой эффектов для видеоредактора с прозрачностью | `background: transparent` → `render` в `WebM · VP9` (или запись в WebM). Проверено в OpenReel |
| Слой для редактора без прозрачности (например мобильный CapCut) | `background: theme` при `light-on-dark` (почти чёрный) → MP4 → в редакторе режим наложения **Screen** |
| Хромакей | `background: color` (зелёный по умолчанию) → MP4 → **Chroma key** в редакторе |
| Радуга по монохромной картинке | `hue-cycle` с `saturation` 0.6–1, `speed` 0.05–0.1 |

## Частые недоразумения

- **`mode: source`, а цвета нет.** Исходник — текст: у него нет цветов, используется цвет темы.
- **Фон `image` + `picture`, а картинки нет.** Исходник — текст; под фоном появится подсказка. Возьмите `custom` и загрузите картинку.
- **Ролик с прозрачным фоном вышел чёрным.** Это MP4 — он не умеет прозрачность. Нужен WebM.
- **Символы не читаются на фото.** Увеличьте `dim`, добавьте `blur`, или включите плашки с небольшой `plate opacity`.
- **Анимация с плашками притормаживает.** Плашки с градиентом при быстрой анимации — самый дорогой режим: перерисовывается каждая ячейка в каждом кадре. Уменьшите `cols` или ограничьте эффект маской.
