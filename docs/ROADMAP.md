# Roadmap

Работаем строго по фазам. Каждая фаза заканчивается зелёным `npm run check`, отчётом и списком того, что проверить в браузере. Отметки `[x]` ставит агент по мере выполнения.

## Фаза 0 — Каркас

- [x] Очистить демо-код шаблона Vite (`counter.ts`, стили, лого).
- [x] `tsconfig`: `strict`, `noUncheckedIndexedAccess`, `noImplicitOverride`, `exactOptionalPropertyTypes`.
- [x] Скрипты: `check` (`tsc --noEmit && vitest run`), `test` (`vitest`).
- [x] Конфиг vitest (environment `node`; тесты, которым нужен canvas, пока не пишем — логику держим в чистых функциях).
- [x] Структура папок из `CLAUDE.md`, модули с экспортом типов из SPEC.
- [x] `index.html`: полноэкранный контейнер с canvas, место под панель.

**Готово, когда:** `npm run check` и `npm run build` проходят; страница открывается без ошибок в консоли.

## Фаза 1 — Статичная картинка

- [x] `core/field.ts`: создание Field, копирование, утилиты индексации.
- [x] `core/ramp.ts`: встроенные рампы, `measureRamp`, квантование (nearest-density и uniform), полярность.
- [x] `core/import-image.ts` по SPEC §3.1 (включая Собеля).
- [x] `core/import-text.ts` по SPEC §3.2.
- [x] `render/atlas.ts`, `render/block-glyphs.ts`, `render/canvas2d.ts` — монохромный рендер.
- [x] `main.ts`: drag-and-drop/выбор файла (изображение или .txt), выбор `cols`, рампы, полярности. Перерисовка при изменении.
- [x] Тесты: квантование, обратный поиск по рампе, импорт текста (выравнивание, табы), Собель на синтетическом поле.

**Готово, когда:** загруженная фотография отображается как ASCII; смена рампы и полярности мгновенно перерисовывает картинку; блоки `░▒▓█` стыкуются без щелей; картинка не растянута по вертикали.

## Фаза 2 — Цикл и cell-эффекты

- [x] `core/loop.ts`, `core/context.ts`, ввод курсора в координатах ячеек.
- [x] `core/prng.ts` (сидированный), `core/noise.ts` (simplex 2D/3D, fbm).
- [x] `effects/types.ts`, `effects/registry.ts` по SPEC §6.
- [x] `pipeline/pipeline.ts`: source→work, применение cell-эффектов через один `CellRef`.
- [x] Эффекты: `wave`, `erosion`, `decode`, `pulse`.
- [x] Debug-оверлей: fps и время по стадиям.
- [x] Тесты эффектов на полях 4×4..8×8 с фиксированным временем и сидом.

**Готово, когда:** эффекты включаются из `main.ts`, анимация плавная, 200×100 укладывается в бюджет SPEC §12 (цифры в отчёте).

## Фаза 3 — Displace

- [x] `core/sample.ts`: билинейная выборка, `distIso`.
- [x] Стадия displace в pipeline (композиция `out`).
- [x] Эффекты: `ripple`, `swirl`, `lens`, `liquid`, `glitch-rows`, `shake`.
- [x] Тесты: нулевое смещение = исходник; билинейная выборка на известных значениях; изотропность ripple (одинаковый радиус по X и Y в пикселях).

**Готово, когда:** рябь от курсора круглая и плавная; символы меняются постепенно, без «лесенки».

## Фаза 4 — Параметры, маски, пресеты, UI

- [ ] `pipeline/params.ts`: LFO и огибающие по SPEC §7.
- [ ] `pipeline/mask.ts` и mix по SPEC §6.4.
- [ ] `presets/preset.ts`: типы, валидация, сериализация. 3–4 встроенных пресета.
- [ ] `ui/panel.ts`, `ui/controls.ts`: панель цепочки (добавить, удалить, переставить, вкл/выкл), автогенерация контролов из схем, переключение число/LFO у числового параметра, сохранение и загрузка пресета.
- [ ] Тесты: LFO в ключевых точках фазы; огибающая с loop; валидация битых пресетов (не бросает, даёт предупреждения).

**Готово, когда:** любой эффект настраивается из панели без кода; пресет сохраняется в JSON и загружается обратно с тем же результатом.

## Фаза 5 — Системы

- [ ] Пул спрайтов в WorkBuffer и их рендер.
- [ ] `particles` (пружина к дому, отталкивание, взрыв по клику, intro-сборка).
- [ ] `trails` (feedback с затуханием).
- [ ] `sand` (осыпание и возврат).
- [ ] Замеры производительности с частицами на 200×100.

**Готово, когда:** частицы держат 60 fps на целевом размере; взрыв и сборка выглядят плавно; системы корректно переинициализируются при смене картинки.

## Фаза 6 — Полировка (по согласованию)

- [ ] Переходы между двумя полотнами (по яркости и через частицы).
- [ ] Рампа как параметр эффекта в маске.
- [ ] Цветной режим с квантованной палитрой.
- [ ] Экспорт кадра в PNG, по возможности — запись WebM через `MediaRecorder`.
- [ ] Экспорт кадра в текст (`.txt`): символы по тому же приоритету, что в рендере (`charOverride → char → quantize`), пустые ячейки — пробелы. Опции: копировать в буфер обмена, обрезать хвостовые пробелы. Спрайты систем не попадают в сетку — решить при постановке. Взята раньше фазы: задача 003.
- [ ] Встраиваемый API: `mount(element, { source, preset })` без панели.
