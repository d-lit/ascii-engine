# Карта документации

Какой документ за что отвечает и кто его ведёт. Публичное описание проекта — в [README](../README.md) в корне.

## Для пользователя

| документ | о чём |
|---|---|
| [guide/](guide/) | Руководство: что делает каждая настройка панели, как сочетать эффекты, цвет и слои, как экспортировать. |
| [PRESETS.md](PRESETS.md) | Подбор пресетов: рабочий цикл, формат файла, приёмы и сочетания, стоимость эффектов. |

## Для разработчиков и агентов

| документ | о чём | кто ведёт |
|---|---|---|
| [SPEC.md](SPEC.md) | Архитектура и контракты: данные, импорт, рампа, pipeline, эффекты, параметры, пресеты, рендер, экспорт. | архитектор |
| [DECISIONS.md](DECISIONS.md) | Журнал решений: контекст → решение → последствия. Новые записи сверху, старые не переписываются. | архитектор |
| [ROADMAP.md](ROADMAP.md) | Фазы, их пункты и критерии готовности. | архитектор |
| [tasks/](tasks/) | Задачи по шаблону [`_TEMPLATE.md`](tasks/_TEMPLATE.md): постановка, отчёт исполнителя, ревью, статус. | постановка — архитектор, отчёт — исполнитель |
| [OPEN-QUESTIONS.md](OPEN-QUESTIONS.md) | Вопросы, которые исполнитель не вправе решать сам, и ответы на них. | исполнитель спрашивает, архитектор отвечает |
| [../AGENTS.md](../AGENTS.md) | Общие правила для всех агентов: стек, команды, инварианты, стиль, завершение задачи. | архитектор |
| [../CLAUDE.md](../CLAUDE.md) | Роль Claude (архитектор и ведущий разработчик). | — |
| [../PROMPT.md](../PROMPT.md) | Стартовые промпты для сессий агентов. | — |

## Где что искать

- **Как работает кадр** — SPEC §10 и поток кадра в `AGENTS.md`.
- **Почему так, а не иначе** — DECISIONS (поиск по номеру из комментария в коде).
- **Что дальше** — ROADMAP; что уже сделано — отметки там же и статусы в `tasks/`.
- **Замеры производительности** — `tests/bench/` (как запускать — в комментариях файлов) и отчёты задач.
